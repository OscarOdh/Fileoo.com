Welcome to Fileoo

Overview & Architecture

FILEOO.COM is a multi-themed, cryptographically secure cloud storage and file-sharing ecosystem. Designed for private repositories and webmasters, it pairs high-performance storage virtualization with access controls.

Core Features

Secured Uploads

Files up to 150MB are sanitized, uniquely tokenized, and stored completely outside the public web root directory.

Cryptographic Links

Create public links protected by unguessable 48-char hex tokens, user-configured passcodes, and download limits.

Internal Collaboration

Share items instantly with other platform users by searching their accounts or emails. Easily retract sharing parameters.

Multi-Theme Core

Inject styling matrices to adjust your storage environment between dark cyberpunk (Matrix), classic dark, and pink themes.

Security Under the Hood

FILEOO utilizes a dual-layer security posture:

  • Protected Storage Structure: Uploaded files live in an isolated directory (e.g. ../fileoo_uploads/) guarded by a strict local .htaccess policy denying direct URL request mapping.
  • Permission-Gated Router: All file streams are dynamically resolved by download.php. It evaluates session tokens, owner permissions, active expiration hashes, and passcode variables before delivering binary data.
  • Host Header Poisoning Defense: All password reset emails and public share links are strictly anchored to an authoritative canonical base URL (APP_URL), eliminating HTTP Host Header injection and token exfiltration vectors.
  • Decompression Bomb Protection: Uploaded raster images undergo a pre-decoding dimension check (capped at 50 Megapixels) before generating thumbnails, preventing memory exhaustion and Denial of Service (DoS) attacks.
  • No Scripting Execution: SVG files are filtered and client-supplied scriptable extensions are prohibited. High-security HTTP headers like X-Content-Type-Options: nosniff prevent browser-level MIME sniffing.
Pro-Tip: The active user session utilizes hardened HTTP-only cookies and cryptographic Cross-Site Request Forgery (CSRF) tokens on all database-mutating requests.

Setup & Configurations

Getting Started

Before uploading files, you must configure your account preferences and align your authentication modules. Let's look at setting up and managing your workspace.

Authentication & Safeguards

FILEOO utilizes a centralized account schema to ensure that your private directory is walled off:

  • Account Registration & Login: Sign up with a unique username and email. The system validates entries and stores credentials using secure password hashing techniques.
  • Cloudflare Turnstile Capture: A Cloudflare Turnstile captcha gate guards key authentication forms to prevent automated credential attacks.
  • Login Rate-Limiting: To block brute-forcing, failed login attempts are written to a temporary login_attempts table with client IP checking. If an IP exceeds threshold rules, authentication requests are throttled.

Account Management

Clicking on your profile on the left sidebar overlay gives you access to configuration modals:

Setting Description Validation Requirements
Change Username Edits username and updates session states. Optionally updates your email. Max 50 characters, letters, numbers, and underscores only. Must be unique.
Change Password Updates the active account's password hash in the database. At least 10 characters. Must contain 1 uppercase letter, 1 lowercase letter, and 1 number.
Delete Account Triggers a cascading deletion across all file shares, uploads, and data tables. Requires checking a warning and confirmation. Removes physical files and thumb caches.
Password Recovery: The forgot password gateway uses forgot.php and reset.php. It relies on a socket-based SMTP client script, send_mail_smtp(), which connects directly to Mail servers without external dependencies.

Data Ingestion

File Uploads & Quota

FILEOO handles files via drag-and-drop actions, monitors physical allocations, and generates thumbnails on demand.

Uploading Files

On the main dashboard card, you can choose local files or drag them directly onto the upload zone:

  • Max Upload Limit: Individual files are limited to 150 MB (aligned to PHP limits).
  • Upload Progress: Once initiated, the upload button transitions into a real-time progress bar.
  • Allowed Formats: The whitelist allows standard document formats (pdf, docx, xlsx), images (jpg, png, webp, gif), audio/video (mp3, mp4, mkv), archives (zip, 7z, tar.gz), and plain data text files (json, csv, md).
Blocked Formats: SVG files (.svg) are strictly prohibited because they can execute vector-based XML scripts inside the browser context, which poses security risks.

Storage Quota & Ring Gauge

Every user has an assigned storage quota (default: 1000 MB), which can be adjusted per-user in the database. Space is computed continuously:

75%
Used
  • Allocation Principle: Only files you own count against your storage quota. Files shared with you count against their original owner's quota.
  • Ring Gauge Design: Desktop displays show a 270° circular open-bottom gauge. Mobile devices compress this into a horizontal storage bar to fit smaller viewports.
  • Busting Uploads: If a batch upload exceeds the remaining quota, the transaction halts and displays a detailed remaining balance error.

Visual Previews & Thumbnails

When raster images (JPEG, PNG, GIF, BMP, WEBP) are uploaded, the server uses PHP's GD library to automatically generate a 400px downscaled thumbnail. These thumbnails are kept in the protected folder and are loaded on-hover in the files list.

Interactive Management

Table Actions & Organization

Manage files through search, column sorting, inline image previews, and bulk selection tools.

File Table Layout

The main dashboard displays files using an interactive, responsive grid list:

  • Sortable Columns: Clicking column header buttons filters files by Name, File Size, or Upload Date. Sort directions alternate on click.
  • Search Filter: Clicking the magnifying glass icon displays a search box to filter files in real-time by keyword as you type.
  • Adaptive Middle Truncation: Long filenames automatically truncate with an ellipsis while keeping the file extension visible at the end (e.g., Quarterly_Report_Financials....pdf) so you can always identify the file format. Hovering or focusing on the link displays the full original filename.
  • Shared File Badges: If another user shared a file with you, it will display a grey badge with the owner's username next to the filename.

Image Previews & Mobile Lightbox

Image files display a preview icon in the file list:

  • Desktop Hover Tooltip: Hovering with a mouse displays a floating thumbnail preview card next to the icon.
  • Touch & Mobile Lightbox Modal: Tapping or clicking the preview icon opens a centered fullscreen Lightbox Modal featuring a crisp high-res preview, filename, and a direct download button. Tap anywhere outside or click × (or press Esc) to dismiss.

Bulk Selection, ZIP Download & Deletion

If you own multiple files, you can select and manage them in batch:

  1. Select All Checkbox: Click the main checkbox in the header row to select all files in your repository.
  2. Individual Selection: Use the row checkboxes on the right to select specific files. Checkboxes only appear on files you own.
  3. Batch ZIP Download: Selecting 2 or more files reveals a blue DOWNLOAD (N) button in the header. Clicking this dynamically compiles all selected files into a single fileoo_files_YYYY-MM-DD-HH(AM/PM)-MM.zip archive (up to 200 MB / 50 files per batch) with automated duplicate filename collision handling.
  4. Batch Delete Button: A red DELETE (N) button also slides into view. Clicking this opens a confirmation modal detailing the items queued for permanent deletion.
Real-time File Check: Double clicking an item or clicking the filename launches the download helper. The system checks permissions and redirects to secure viewer layers for images and audio files.

Access Management

Sharing & Public Links

FILEOO provides two distinct file-sharing modes: secure internal sharing with other registered users, and custom public download links.

1. Internal User Sharing

Click the SHARE button on any file row to share it with another platform user:

  • Share Target: Enter the target user's username or email. The server verifies the recipient exists before updating permissions.
  • Rights Retraction: File owners can view active shares in the share modal and click a revoke action to remove access instantly.
  • Unshare Self: If a file is shared with you, click UNSHARE on your row to remove yourself from the share list.

2. Custom Public Links

Click the LINK action button to configure a temporary public download URL. The modal allows you to configure several security limits:

Security Limit Options Purpose
Expiration Range 1h, 1d, 7d, 30d, 1y, or Never Sets an expiration date/time after which the link returns a 410 Gone error.
Download limit 1, 5, 20, 100, or Unlimited Max download count limit. The link is automatically disabled when the limit is reached.
Passcode Custom string input (Min 4 chars) Requires visitors to enter a passcode to download the file. The passcode is stored securely as a hash.

The Passcode Gate Guard

When a public link has passcode protection enabled, visitors are prompted to enter the passcode to download the file:

  • Brute-Force Prevention: The server prompts for the passcode and validates it using password_verify() via POST.
  • Bot Protection: Link-scraping bots and search engine crawlers cannot bypass the passcode prompt, which prevents them from consuming the download limit.

Knowledge Base

FAQs & Settings

Answers to common questions, platform settings, and details about administrative tools.

Custom Themes

FILEOO supports multiple user interface themes. Change your theme from the dropdown selector at the bottom of the left sidebar:

  • Matrix (Default): A green-and-cyan cyberpunk theme featuring a matrix code fall canvas background.
  • style_Dark.css: A classic dark-slate theme with clean lines.
  • style_Pink.css: A high-contrast magenta and pink neon theme.

Theme selections are saved to the database (users.selected_css) and persist across sessions.

Frequently Asked Questions

Question Resolution
Why is my upload failing with a size error? Files must be under 150MB. Make sure the file size does not exceed the limit or your remaining storage quota.
How are long filenames handled in the dashboard? Long filenames use adaptive middle truncation so that the beginning of the title and the file extension (e.g. .pdf, .docx) remain visible at all times. Hovering over any truncated filename reveals the complete name.
How are image uploads protected against memory DoS? FILEOO reads image dimensions via header metadata prior to decoding. Images exceeding 50 Megapixels are rejected for thumbnail generation to protect server memory against decompression bombs.
Can I upload script files like SVG or PHP? No. SVG and scripting formats are blocked to prevent cross-site scripting (XSS) and server-side code execution.
What happens to my shares when I delete a file? Deleting a file automatically deletes all associated public links and internal shares in the database.
How do I recover a deleted file? File deletions are permanent. Files are immediately deleted from disk and cannot be recovered.

OPcache Reset Tool

Administrators can use the OPcache reset tool:

  • File Location: clear_cache.php
  • Functionality: Runs opcache_reset() on the server to clear cached PHP code in memory, forcing the server to load updated files.
